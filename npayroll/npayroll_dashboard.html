About this module

The Nursery Payroll System keeps the worker register, the monthly pay periods and every earning and deduction that makes up a worker's pay. Its tables use the mjmnpayroll_ prefix.

Piece-rate work done in the nursery is recorded in Work Maintenance; this module is where that becomes pay.

Module access is granted per user on the main portal's User Access.
