User Access Setting

This is the main access management for the whole AI System — it decides which module cards each user sees on the module-selection page, and at what level. Only staff who signed up through the AI System appear below; Salesweb customers are kept out of this list to keep it clean.

  • Edit Access on a row — set each module's level and toggle Manage Users. Finer settings (which pages inside a module, batch verifier…) are managed inside each module's own User Access page.
  • + Add User — pull a customer in from the Salesweb list and promote them to a system user.
  • Inside the panel, Move to customer sends them back out (their access is cleared).

—

Looking for someone who isn't listed? Switch to All Accounts — Salesweb customer sign-ups are there, with an Open Access button to promote them.
