Setting up the portal

The field app is built for a phone in a plot, so setting it up is done here on a screen where the whole picture fits. Whether somebody can open the 555 FC Portal at all is decided on the main User Access; everything below that — which pages they see, what they may do on each, and which nurseries they are shown — is set here.

🔐 User Access Which pages each person opens, what they may do inside, and which nurseries they see 🪴 PALMS Monitoring Board What every plot is on today, and what is running late 🚦 Plot Status Stages The statuses PALMS lets a Field Conductor choose from — on Life of Plot 🌱 Plots Which plots exist — kept in Seedling Stock Management

Field Conductors go straight to the phone app from the module selection — they never see this page.
