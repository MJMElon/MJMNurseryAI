User Setting

Nursery Case Log is linked to the modules below. A case raised in a module belongs to that module's block. Add the people who handle each one, then narrow each person to the case categories they should see.

How visibility works

Somebody who appears in no block at all sees every case — so nothing goes dark the day you switch this on. Once they appear in a block, they see only those modules, and only the categories ticked for them. A Nelos admin always sees everything.

Whether somebody can open Nelos at all is still set on the main portal's User Access. This page decides what they see once they are in.
